
# CharacterAI — Casados con Hijos

### Proyecto Integrador | Módulo 3 — Henry

**Autor:** Gonzalo Barbaglia  
**Cohorte:** CH80

## Sobre el proyecto

CharacterAI es una aplicación web que permite conversar con personajes ficticios mediante inteligencia artificial.

Para este proyecto elegí trabajar con los cuatro integrantes de la familia Argento, de la serie argentina Casados con Hijos:

- Pepe Argento.
- Moni Argento.
- Coqui Argento.
- Paola Argento.

Cada personaje cuenta con su propia personalidad, forma de expresarse, saludo inicial e historial de conversación independiente.

La aplicación fue desarrollada utilizando JavaScript, HTML y CSS, integrando la inteligencia artificial de Google Gemini mediante una función serverless en Vercel.

Este proyecto fue desarrollado con fines educativos. No es una aplicación oficial ni está afiliada a los titulares de los derechos de Casados con Hijos.
